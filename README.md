# CORTAQUI

CORATAQUI é um sistema de barbearia desenvolvido para a barbearia Tradição do Boleiro dentro da disciplina de Projeto de Software da UEPG.

Esse projeto foi bootstrapped com `create-t3-app`.

## Documentação do Tech Stack

- [Next.js](https://nextjs.org)
- [Drizzle](https://orm.drizzle.team)
- [Tailwind CSS](https://tailwindcss.com)

## Deployment

Deployment automaticamente feito via [Netlify](https://create.t3.gg/en/deployment/netlify) assim que um pull request for mergeado.
